## 新增素材怎么加

1. 丢进 `Assets/Resources/Art/` 对应子目录，按上表命名。
2. 菜单 `CatFight → Assets → Fix Import Settings`（自动设为 Sprite、不压缩）。
3. 直接运行，代码会自动加载；缺图时自动退回程序生成的占位图形。

## 白底抠图

素材（猫图、立绘、卡图）都带白背，直接叠在照片/纸面上会露出白块。
`Assets/Shaders/WhiteKeyUI.shader` 会把接近白色的像素变透明（可调 `_Threshold` / `_Softness`），
由 `UI.Assets2.ApplyWhiteKey(image, threshold, softness)` 应用。

## 音频

`Core/AudioDirector.cs`：进战斗先播 `battle_start`，播完自动淡入 `battle_loop` 循环；
离场淡出。音量由设置面板的「音量」滑块实时控制（同时写入存档）。
